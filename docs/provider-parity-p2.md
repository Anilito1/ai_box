# Statistiques et parité des moteurs — P2

Vérifié le 3 novembre 2026. Ce document décrit les correctifs et les limites, sans promettre les fonctionnalités d'un autre moteur.

- **Coûts** : estimation USD aux tarifs API texte standard des modèles explicitement présents dans `src/main/providers/pricing.ts`. Sources : [OpenAI](https://developers.openai.com/api/docs/pricing), [GPT-5.2-Codex](https://developers.openai.com/api/docs/models/gpt-5.2-codex), [Gemini](https://ai.google.dev/gemini-api/docs/pricing). Les abonnements, gratuités, frais d'outils, stockage du cache, audio, tarifs rapides et remises ne sont pas une facture API standard. Les modèles inconnus gardent leurs jetons mais leur coût reste non chiffré (0 dans le stockage actuel) : cette valeur ne garantit pas la gratuité. Actualiser la table quand les modèles ou tarifs changent ; aucune récupération des anciens coûts à zéro.
- **Codex** : les compteurs de conversation sont différenciés avant attribution au modèle courant ; les notifications répétées ne refacturent pas les jetons et un changement de modèle ne revalorise pas les anciens tours. Le premier instantané d'une conversation reprise reste la référence si le serveur n'a pas fourni les totaux avant le premier résultat : ce premier tour peut ne pas être comptabilisé. L'attribution des tours historiques au modèle exact n'est pas reconstructible avec un compteur global seul.
- **Gemini, reprise** : les totaux sont transmis au nouveau processus et sauvegardés avec l'état local des sessions. L'historique rejoué ne s'ajoute pas aux coûts. Un ancien état sans totaux détaillés conserve les coûts déjà affichés et démarre le détail des jetons à zéro ; les nouveaux tours s'y ajoutent. Une nouvelle conversation démarre sans ancienne référence.
- **Gemini, jetons** : lecture de `_meta.quota.model_usage`, repli sur `usage` standard ou `_meta.quota.token_count`. Quand un seul modèle est connu, `usage` permet de distinguer cache et réflexion. Avec plusieurs modèles, le cache et la réflexion globaux ne peuvent pas être attribués exactement : les seules valeurs par modèle sont utilisées. Sur les anciennes versions ne fournissant que `_meta`, la réflexion/cache ne sont pas séparables. Les paliers longs utilisent les jetons d'entrée du prompt agrégé ; un prompt contenant plusieurs appels de tailles différentes reste une approximation.
- **Gemini, quotas** : `quota.token_count` exprime une consommation, pas un pourcentage restant. Aucun endpoint de fenêtres de quota n'est exposé par ACP ; `rateLimits()` reste `null`. Les erreurs 429/quota et les délais de reprise annoncés sont déjà relayés. Aucune fausse fenêtre de cinq heures ou sept jours n'est créée.
- **Gemini, effort** : le catalogue annonce `noEffort` et aucun niveau. ACP ne fournit pas de réglage du budget de réflexion ; une demande directe est désormais refusée explicitement au lieu d'être ignorée.
- **Gemini, commandes** : `available_commands_update` alimente les commandes de la session, y compris lors d'un chargement. Les commandes de Claude ne servent plus de liste de repli à Codex/Gemini. Seules les commandes annoncées par le fournisseur sont proposées.
- **Gemini, consignes** : ACP ne possède pas de champ d'instructions système équivalent à `developerInstructions` de Codex. Les consignes actuelles ouvrent le premier message conversationnel de chaque lancement, y compris une reprise. Si les premiers messages sont des commandes `/` ou `$`, ils sont transmis intacts et les consignes restent en attente jusqu'au prochain message conversationnel. Aucune requête modèle supplémentaire n'est ajoutée ; une commande qui déclenche elle-même un appel modèle reste soumise aux consignes déjà présentes dans la conversation. Elles restent du contenu utilisateur, avec le niveau de priorité correspondant ; aucun fichier du dépôt n'est créé pour simuler une instruction système.
- **Gemini, dossiers additionnels** : le CLI découpe inconditionnellement les valeurs `--include-directories` sur les virgules et retire les espaces périphériques. Aucun échappement documenté : une telle valeur provoque désormais une erreur explicite au lieu d'une omission silencieuse. Pas de lien symbolique ni de modification de la configuration utilisateur pour contourner cette limite.

Contrats Gemini recoupés dans les sources officielles : [ACP](https://github.com/google-gemini/gemini-cli/blob/main/packages/cli/src/acp/acpSession.ts), [arguments du CLI](https://github.com/google-gemini/gemini-cli/blob/main/packages/cli/src/config/config.ts). Validation locale par protocoles simulés ; aucun compte réel, quota réel ni facture réelle interrogé.
